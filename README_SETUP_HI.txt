KAILU CREATION — Google Sheets + Email Order Setup (FREE)

WHAT THIS DOES
- Customer chooses catalog item(s), size, name and delivery address.
- Google Apps Script saves order details to a Google Sheet and emails a notification.
- COD is recorded as the requested payment method.
- Google account quotas and terms apply.

ONE-TIME SETUP
1. Sign in to the Google account where you want to receive order emails.
2. Create a new Google Sheet named "KAILU CREATION Orders".
3. Copy the Sheet ID from the URL:
   https://docs.google.com/spreadsheets/d/THIS_IS_THE_SHEET_ID/edit
4. In the Sheet, click Extensions > Apps Script.
5. Open Code.gs, remove the starter code, and paste the supplied Code.gs file.
6. In Code.gs change STORE_EMAIL = "YOUR_EMAIL@example.com" to the email address where you want order alerts.
7. Change SHEET_ID = "PASTE_YOUR_GOOGLE_SHEET_ID_HERE" to the Sheet ID from step 3.
8. Click Save.
9. Click Deploy > New deployment > select Web app.
10. Set "Execute as" to Me and "Who has access" to Anyone.
11. Click Deploy and authorize the requested permissions. Review the permission prompt carefully.
12. Copy the Web app URL ending in /exec.
13. Open the website's script.js in a text editor. Find:
   const GOOGLE_SCRIPT_URL = "PASTE_YOUR_GOOGLE_APPS_SCRIPT_WEB_APP_URL_HERE";
   Replace the placeholder with your full /exec URL, keeping the quotation marks.
14. Save script.js. Open index.html and place a test order with your own test details.
15. Check the Google Sheet and email inbox/spam folder. Do not publish until this test works.
16. If you edit Apps Script later, use Deploy > Manage deployments > Edit and deploy a new version.

FILES
- index.html: storefront structure
- style.css: design
- script.js: cart and order submission; configure GOOGLE_SCRIPT_URL
- images/: the three catalog photos
- Code.gs: Google Apps Script backend

IMPORTANT
- This is a free starter setup, not a managed e-commerce platform. Google quotas/terms can change.
- The public web app URL can receive spam submissions; check orders before fulfillment.
- Because browser cross-origin requests cannot read the Apps Script response in this simple setup, the page can only indicate that the request was sent. Verify the first test order appears in the sheet and email.
- Email is sent from the Google account owning the script to STORE_EMAIL.
- COD availability, stock, delivery and final confirmation remain the store's responsibility.
- Do not collect card numbers, passwords or other sensitive information.
